# 项目摘要

## 问题背景

原始目标不是做一个纯论文式 benchmark，而是做一个更贴近真实场景的图片内容审核原型。

## 解决方案

项目使用 ResNet101 作为共享主干，并把输出拆成两个任务：

- 风险等级分类
- 内容类型分类

相比单一的二分类 NSFW 判断，这种方式能输出更丰富的结果。

## 工程工作

- 图片采集与基于数据库的标注流程
- 针对坏图和极端宽高比图片的预处理
- 模型训练与权重管理
- Flask 推理服务
- Vue 演示与标注界面

## 公开版整理策略

- 移除了生产环境凭据和私有服务地址
- 排除了数据集、备份文件和模型权重
- 增加了适合公开展示的简化版前后端入口
- 保留了部分 legacy 代码，用于说明项目原始结构
